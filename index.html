Langkah 4 dari 9 System Prompt Rulebook

Memasang Dokumen Aturan AGENTS.md

Buat file bernama AGENTS.md di dalam folder proyek Anda, lalu tempel isi aturan ini. Hermes Agent akan membaca file ini sebelum mulai menulis kode.

Pratinjau: AGENTS.md (4 Batasan Pokok Game) Wajib Dipatuhi AI
1. Pure Vanilla Web (Zero-Build) Kode wajib murni HTML5, CSS3, dan JS murni. Game harus langsung bisa dimainkan cukup dengan klik ganda berkas index.html di Google Chrome tanpa install server Node.js.
2. Penyimpanan Rekor (LocalStorage High Score) Skor tertinggi wajib tersimpan otomatis di browser menggunakan localStorage.setItem() dan localStorage.getItem(). Rekor tidak boleh hilang saat halaman direfresh!
3. Siklus Layar Game yang Jelas (State Machine) Memiliki 3 tampilan rapi: Layar Awal (Start Screen + panduan tombol), Layar Bermain (HUD skor berjalan), dan Layar Game Over (skor akhir + tombol "Main Lagi").
4. Efek Suara Mandiri (Web Audio API Synthesizer) Dilarang menggunakan file mp3 eksternal (rentan error 404). Gunakan native window.AudioContext untuk suara loncat, tangkap poin, dan kalah, lengkap dengan tombol Mute/Unmute.
💡 Dengan berkas ini, AI tidak akan membuat kode yang salah jalur atau menggunakan framework yang rumit.

Langkah 6 dari 9 Eksplorasi Kreatif

Memilih Ide & Tema Game 2D Arcade

Siswa bebas memilih salah satu tema game di bawah ini (atau membuat tema kreasi sendiri), asalkan tetap mematuhi batasan teknis di AGENTS.md.

🐍 1. Retro Neon Snake

Klasik

Kendalikan ular yang memakan item neon. Setiap makan, ular bertambah panjang dan kecepatan meningkat. Menabrak badan sendiri atau dinding = Game Over.

Kontrol: Panah / WASD | HighScore: Panjang & Skor

🚀 2. Space Asteroid Dodger

Aksi

Pesawat luar angkasa bergerak ke kiri/kanan untuk menghindari hujan asteroid yang jatuh secara acak. Terdapat item perisai pelindung (Shield Power-up).

Kontrol: Kiri/Kanan/Spasi | HighScore: Detik Bertahan & Skor

🧺 3. Falling Fruit Catcher

Ketangkasan

Gerakkan keranjang untuk menangkap buah/koin yang jatuh dari langit. Jika menangkap bom atau melewatkan 3 buah berharga, permainan berakhir.

Kontrol: Panah Kiri/Kanan | HighScore: Total Poin Tangkapan

🕊️ 4. Cyber Flappy Bird

Refleks

Tekan Spasi untuk mengepakkan sayap dan menjaga ketinggian karakter agar tidak menabrak pilar pipa rintangan di depan.

Kontrol: Tombol Spasi / Klik | HighScore: Rintangan Terlewati

Langkah 7 dari 9 Prompt Engineering

Format Prompt Instruksi ke Hermes Agent

Ketik atau salin teks prompt di bawah ini ke kotak masukan Hermes Agent. Ganti bagian tema sesuai pilihan Anda.

Template Prompt Teruji (Siap Salin) 
Halo Hermes Agent, saya sedang membangun sebuah game 2D Arcade web dengan tema: [TULIS TEMA ANDA, misal: Retro Snake / Space Dodger / Catching Items].

Bekerjalah di folder proyek ini dan BACA seluruh aturan teknis pada berkas AGENTS.md sebelum mulai coding.

Tugas Anda:
1. Bangun antarmuka game modern dan terpusat di berkas index.html.
2. Buat desain CSS bertema arcade yang estetik, rapi, dan responsif di style.css.
3. Tulis seluruh logika game di game.js dengan fitur wajib:
   - High Score tersimpan permanen menggunakan browser localStorage.
   - 3 State layar yang jelas: Start Screen, Playing HUD, dan Game Over Screen (dengan tombol Main Lagi / Restart).
   - Efek suara audio synthesizer native (Web Audio API) untuk aksi lompat/tangkap, skor poin, dan game over, lengkap dengan tombol Mute/Unmute.
4. Gunakan relative path (./style.css dan ./game.js) agar kompatibel saat di-hosting di GitHub Pages.
5. Pastikan game dapat dimainkan dengan kontrol keyboard yang lancar dan bebas error.
⚙️ Proses AI: Hermes Agent akan membuat berkas index.html, style.css, dan game.js dalam beberapa saat. Bebas revisi jika ingin menambah fitur!
